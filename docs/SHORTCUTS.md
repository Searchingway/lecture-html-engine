# 快捷键

| 按键 | 功能 |
|---|---|
| `Space` | 显示下一条；本页全部显示后翻页 |
| `←` / `→` | 上一页 / 下一页 |
| `Home` / `End` | 全课件首 / 末页 |
| `N` / `P` | 下一课 / 上一课 |
| `C` | 课程目录 |
| `M` | 知识地图 |
| `O` | 全书总览 |
| `/` | 搜索 |
| `D` | 讲稿 |
| `E` | 批注模式 |
| `H` | 返回课程首页 |
| `F` | 浏览器真全屏 |
| `Ctrl+Z` | 撤销笔迹 |
| `Ctrl+Shift+Z` | 重做笔迹 |
| `Esc` | 关闭弹窗 / 退出批注模式 |

批注工具栏中可切换画笔、荧光笔、橡皮、颜色与笔宽。批注数据默认保存在浏览器 `localStorage` 中。
