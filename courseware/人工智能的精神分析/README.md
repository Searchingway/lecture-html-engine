# 《人工智能的精神分析》系列课程

当前公开版为 **23 节 / 175 页重构版**。

- EVA-inspired 黑 / 橘 / 米白高对比主题
- 每页只完成一个明确教学动作，不再固定“三条 bullet”
- 页面内部可分别标注【书中观点】【解释性转述】【我的延伸】
- 第 1、2 课保留原有页数和顺序，文字做教学性校准
- “蓝脑”与“反哲学”拆为两课
- 性化公式保留上下两课共 20 页；四大辞说保留 16 页细讲
- 核心课程尽量忠于原书，ChatGPT / 手机 / 推荐算法等现代例子不再占据主线
- 结尾保留“蛇妖 ↔ 大卫”的首尾闭环，并停在“数元与焦虑之间”
- 支持真全屏、逐条显示、讲稿、课程目录、搜索与数位板批注
- 可离线运行，不需要 npm 或服务器

## 观众如何下载课件

GitHub 不提供原生“下载单个文件夹”按钮，因此最稳妥的方法是：

1. 回到仓库首页。
2. 点击绿色 **Code** 按钮。
3. 选择 **Download ZIP**。
4. 解压 ZIP。
5. 打开：

```text
courseware/人工智能的精神分析/index.html
```

建议使用最新版 Chrome 或 Edge。

## 为什么不是只有一个 HTML 文件

通用演示引擎放在仓库 `engine/` 中，课程内容放在本目录。这样全屏、批注、搜索和视觉样式只维护一套；以后其他课程也能复用。

旧版 215 页数据仍保留在仓库历史/旧数据文件中，但当前 `index.html` 已切换到 175 页重构数据，不再加载旧课件包。
