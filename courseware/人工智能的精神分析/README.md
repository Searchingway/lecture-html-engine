# 《人工智能的精神分析》系列课程

- 215 页系列讲课 HTML
- 黑 / 橘 / 米白高对比主题
- 支持真全屏、逐条显示、讲稿、课程目录、搜索与数位板批注
- 可离线运行，不需要 npm 或服务器

## 观众如何下载课件

GitHub 不提供原生“下载单个文件夹”按钮，因此最稳妥的方法是：

1. 回到仓库首页。
2. 点击绿色 **Code** 按钮。
3. 选择 **Download ZIP**。
4. 解压 ZIP。
5. 打开：

```text
courseware/人工智能的精神分析/index.html
```

建议使用最新版 Chrome 或 Edge。

如果仓库启用了 GitHub Pages，也可以直接在线打开课件，无需下载。

## 为什么不是只有一个 HTML 文件

这一版把通用演示引擎放在仓库的 `engine/` 中，课程内容单独放在本目录。这样以后更新全屏、批注、搜索或视觉样式时，所有课程都可以复用同一套引擎，而不用维护很多份重复代码。

## 内容说明

原书 PDF **未包含在公开仓库中**。本目录只发布讲课课件、课程结构和运行所需的前端文件。
