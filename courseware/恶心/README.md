## 课程思路

不把《恶心》做成“存在主义概念百科”，而是按小说中的经验推进：

**陌生 → 故事 → 罗尔邦 → 重复与现成意义 → 意义收缩/现实膨胀 → 栗树根 → 安妮 → 分别以后 → 音乐与创作 → 我的回应**
