# 《谜踪之国》讲解课件

- 76 页
- 讲解定位：剧情梳理 + 世界观拆解 + 因果 / 知识边界问题
- 视觉：黑白素描、旧纸、地下遗迹、极少量暗绿色；章节与关键节点使用本地 WebP 插画资源
- 操作：
  - `← / →`：翻页
  - `F`：全屏
  - `O`：页面总览
  - `N`：讲稿 / 备注
  - `E`：开启 / 退出批注模式
  - `Ctrl+Z`：撤销笔迹
  - `Ctrl+Shift+Z`：重做笔迹
  - `Home / End`：首尾页

## 批注

课件保留讲课用透明 Canvas 批注层，支持：

- 画笔
- 荧光笔
- 橡皮
- 多种颜色
- 笔宽调节
- 撤销 / 重做
- 清除当前页
- 按页自动保存到浏览器 `localStorage`

批注开启后，画布只覆盖 16:9 演示区域，不影响顶部控制栏和两侧翻页按钮。

## 制作说明

本课件按“讲解型视觉课件”制作：重点结构页使用因果闭环、解释路径、递归石碑与三结局图；章节海报与关键叙事页使用本地黑白插画。即使课件采用独立页面渲染器，也必须保留仓库统一的讲课能力，尤其是全屏、总览、讲稿与数位板批注，不得因视觉重构而删减这些功能。
